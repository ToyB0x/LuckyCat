# 自分たちに合う製品を選ぶ

LuckyCatは、十分な時間を割けないチームに向けた、シンプルで手頃なFinOpsに集中します。あらゆる専門製品の置き換えは目指しません。この表は必要なことと製品の方向を比較するもので、特定の競合の機能・料金を検証した比較ではありません。

| 必要なこと | LuckyCatの方向 | より高度な製品が向く場合 |
| --- | --- | --- |
| 導入と日常利用 | 初期設定を軽くし、日常の手間を小さくする | 個別の業務に合わせるため、設定に時間をかけられる |
| コストの把握と改善 | 分かりやすい根拠と、役立つ次の行動を示す | 深い分析や個別の調査が重要 |
| 配賦と組織管理 | 簡単な費用分類・可視化・共有を目指す | 高度な配賦や複雑な組織構造への対応が必要 |
| 統制 | 対象ユーザーに必要な要件に集中する | 専門的な統制や高度なFinOps運用が必要 |
| 予算 | 無料の基本機能または十分な無料枠と、安価な有料領域。上限は未定 | 追加機能が、その費用に見合う価値を持つ |
| 要件の成長 | 紹介、連携、移行支援を検討する | 必要な範囲に合う専門サービスがすでにある |

この表は製品方針です。LuckyCatのFinOps機能は[まだ利用できません](./getting-started)。連携や紹介提携も未成立です。実際の製品を選ぶ際は、その時点の機能と条件を確認してください。

## クラウド標準ツールとの関係

公式ツールにも、リソースのタグ変更を必須としない費用分類があります。[AWS Cost Categories](https://aws.amazon.com/aws-cost-management/aws-cost-categories/faqs/)は、アカウントやサービスなどのルールで費用を分類でき、サービス自体は無料です。[Azureのタグ継承](https://learn.microsoft.com/en-us/azure/cost-management-billing/costs/enable-tag-inheritance)は、上位のタグをリソース自体ではなく利用明細へ適用します。利用条件や関連サービスの費用は個別に確認してください。

機能の使える範囲も選定の材料です。例えば、[AWSのSplit charge rules](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/splitcharge-cost-categories.html)による配賦結果はカテゴリ詳細ページに表示され、Cost ExplorerやCURには反映されません。

| 自分たちの状況 | 選び方 |
| --- | --- |
| 標準ツールで分類・把握・共有ができている | その活用を継続する。 |
| 分類の柔軟さや操作、関係者への共有に不足・負担がある | LuckyCatが補完を目指す対象。仮想タグと簡易Showbackは未提供の候補として検討中。 |
| 複雑な社内請求や会計処理が必要 | 要件に合う専門製品を検討する。 |

LuckyCatは、リソースを書き換えずに費用を分類し、必要な人が理解できる形で共有する一連の体験を重視します。分類・配賦の存在自体を独自機能とはせず、設定・判断・共有の負担をどこまで減らせるかを検証します。

## 選択と協力の両方を大切にする

利用者は必要十分な機能を手頃に使え、LuckyCatはシンプルさと運営効率を保ち、専門サービスは適した顧客と出会い、成長した顧客は次の製品へ進める関係を目指します。企業規模だけで適合性は判断しません。

公式ツール以外の先行・類似プロダクトの実名比較は、調査後に追加します。未検証の機能・価格の主張や順位付けはしません。対象ユーザーと価格の考え方は[製品方針](./product)を参照してください。
