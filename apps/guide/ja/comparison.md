# 自分たちに合う製品を選ぶ

LuckyCatは、十分な時間を割けないチームに向けた、シンプルで手頃なFinOpsに集中します。あらゆる専門製品の置き換えは目指しません。この表は必要なことと製品の方向を比較するもので、特定の競合の機能・料金を検証した比較ではありません。

| 必要なこと | LuckyCatの方向 | より高度な製品が向く場合 |
| --- | --- | --- |
| 導入と日常利用 | 初期設定を軽くし、日常の手間を小さくする | 個別の業務に合わせるため、設定に時間をかけられる |
| コストの把握と改善 | 分かりやすい根拠と、役立つ次の行動を示す | 深い分析や個別の調査が重要 |
| 配賦と組織管理 | シンプルな範囲に絞る | 高度な配賦や複雑な組織構造への対応が必要 |
| 統制 | 対象ユーザーに必要な要件に集中する | 専門的な統制や高度なFinOps運用が必要 |
| 予算 | 無料の基本機能または十分な無料枠と、安価な有料領域。上限は未定 | 追加機能が、その費用に見合う価値を持つ |
| 要件の成長 | 紹介、連携、移行支援を検討する | 必要な範囲に合う専門サービスがすでにある |

この表は製品方針です。LuckyCatのFinOps機能は[まだ利用できません](./getting-started)。連携や紹介提携も未成立です。実際の製品を選ぶ際は、その時点の機能と条件を確認してください。

## 選択と協力の両方を大切にする

利用者は必要十分な機能を手頃に使え、LuckyCatはシンプルさと運営効率を保ち、専門サービスは適した顧客と出会い、成長した顧客は次の製品へ進める関係を目指します。企業規模だけで適合性は判断しません。

先行・類似プロダクトの実名比較は、調査後に追加します。未検証の機能・価格の主張や順位付けはしません。対象ユーザーと価格の考え方は[製品方針](./product)を参照してください。
