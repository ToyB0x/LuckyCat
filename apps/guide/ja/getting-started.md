# 提供状況とはじめ方

::: info 製品の業務フローはまだ利用できません
LuckyCatの製品方針は決まっていますが、顧客向けのFinOps機能は未実装です。利用登録、クラウド接続、検知、通知、紹介、本番セルフホストの利用手順はまだ提供していません。
:::

## 現在あるもの

日英ガイドで製品の方向を説明しています。リポジトリにはWeb・APIのHello Worldと、認証・DBアクセスの初期化関数もあります。これらは開発の土台であり、利用可能なFinOpsサービスや試験提供版ではありません。

まずは[製品方針](./product)と[適合性の比較](./comparison)で、LuckyCatが誰に向いているかを確認できます。ガイドを読むためにクラウド認証情報や顧客データは必要ありません。

## 開発予定

**v0.1予定・未提供：** 次の開発範囲はGoogle Cloudの連携セットアップと初回診断です。連携を設定する → アクセスを確認する → 対象範囲のデータを取得する → ルールを評価する → 改善候補と根拠を確認する体験を予定しています。

準備・権限・解除は[連携の計画](./google-cloud)、結果と制約は[診断とルール候補](./diagnostics)を参照してください。Google Cloudとこの体験は確定し、認証方式、個別ルールの採用、閾値、正確な権限は未確定です。実行できる製品の設定手順はまだありません。

自動変更、AWS・Azure対応、リセラー紹介、植林、感謝、バッジ、プロフィール、高度な配賦・社内請求、全モック画面・全ルールの実装、定期実行、Slack通知は今回のv0.1に含めません。3つの価値の柱は長期的な方向として維持します。

### 検討中の機能

リソースを変更せずに費用を分類・共有する方向を維持します。以下の候補は初回診断より優先度を下げ、v0.1の必須条件にはしません。開発範囲・無料枠・対象バージョンは未定です。

| 候補                 | 目的・予定する体験                                                                             | 制約・状態                                                                                                                        |
| -------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 仮想タグ・仮想ラベル | 取り込んだ費用データに分類ルールを設定し、チームやプロダクト別の金額と未分類の費用を確認する。 | 分類はLuckyCat内に保持し、リソースのタグやTerraformには書き戻さない。分類の細かさは取得データに依存。未提供・対象バージョン未定。 |
| 簡易Showback         | 分類した費用と根拠を、閲覧範囲を限定して関係者と共有する。                                     | 社内請求・会計処理は対象に含めない。共有費用の配賦方法は未定。未提供・対象バージョン未定。                                        |

「予定」の表記は上記のGoogle Cloud連携・診断に適用します。「試験提供」「提供中」は将来の状態の表記例であり、利用可能になったという告知ではありません。

| 表記例           | 意味                                                 |
| ---------------- | ---------------------------------------------------- |
| v0.1予定・未提供 | 対象バージョンは決まっているが、まだ利用できない。   |
| v0.1・試験提供   | 制約を明記したうえで、試験利用できることを確認済み。 |
| v0.1・提供中     | 記載した範囲で利用できることを確認済み。             |

バージョンだけで利用可能とは判断しません。提供時期、料金、無料枠、導入方式、製品ライセンスは未決定です。
