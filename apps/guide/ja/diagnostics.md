# 初回診断とルール候補

::: info v0.1予定・未提供
明示的に選んだGoogle Cloudプロジェクトからデータを取得し、改善候補と根拠を示す初回診断を予定しています。個別ルールと閾値は提供に向けた採用が未確定です。顧客が利用できる診断サービスはまだありません。
:::

まずは[Google Cloud連携の計画](./google-cloud)を参照してください。提供後は、接続と対象を確認して診断を明示的に開始し、その実行結果を確認する流れを想定しています。

次の開発対象は、未接続ディスクと未割り当ての静的外部IPv4です。現在の状態に基づく候補と根拠を確認します。ローカル開発画面では、利用感を確認するための概算金額も表示します。停止VMのディスクは、停止期間と除外条件の決定後に進めます。

## 初回の候補

Compute Engineのリソース情報を共有し、導入負担を小さくできるルールを優先します。以下は採用推奨の候補であり、すべての提供を約束するものではありません。

| 候補 | 見直しに役立つこと | 根拠と制約 |
| --- | --- | --- |
| 未接続の永続ディスク | 現在アタッチ先がないディスクを保持する必要があるか。 | 取得時点の接続関係とリソースの状態。作成からの経過時間は未接続だった期間を示さず、復旧・移行用の保持も考慮する。 |
| 未割り当ての静的外部IPv4アドレス | リソースから現在参照されていない予約済みアドレスが必要か。 | アドレス種別、予約状態、参照先。内部アドレスとIPv6はこの候補から除外し、再利用予定や復旧要件を確認する。 |
| 停止VMに残るディスク | 停止が続いているVMに接続されたストレージを見直せるか。 | ディスクとVMの対応、VMの状態、停止時刻。稼働中や未確認の接続先があれば、すべての接続先が停止しているとは判断できない。保存データが必要な場合もある。 |

最初の2候補は現在のリソース一覧を使います。連続した未使用期間を示すには履歴が必要で、作成時刻では代用しません。停止VMの候補には、信頼できる停止時刻と合意した経過期間が必要です。猶予期間、除外条件、対応するリソース種別は提供前に確定します。

スナップショットの保持見直しは、保持目的と期間の合意が必要な別候補として残します。低利用・サイズ最適化のルールは、追加の監視データと観測期間が必要なため優先度を下げます。いずれの候補も、安全に削除できる保証ではありません。


::: warning 価格推定は現在仮実装です
ローカル開発画面の利用感を確認するため、固定単価で概算月額を表示します。実請求額や確定した削減額ではありません。地域差、割引、無料枠、BYOIPなどの個別条件は反映していません。金額不明の候補は残し、小計には算出できた候補だけを含めます。削除・解放でき、代替費用が発生しない場合の削減目安として扱います。

正式採用時に、BigQueryのBilling Export、価格REST API、その他の情報を組み合わせる方法を検討します。現在は価格の動的取得や自動更新は行いません。顧客向け機能は引き続き未提供です。
:::

## 結果の読み方

提供予定の結果画面では、候補一覧からリソース名・場所・取得時点・判定根拠を確認できるようにします。取得できなかった範囲と未評価の理由も示し、JSONを読まなくても候補と制約を把握できる体験を目指します。

| 状態 | 意味 |
| --- | --- |
| 認証できた | 接続が認証情報を取得できた。データへのアクセスは別途確認する。 |
| データを取得できた | 記録された時点に、明示した取得元・範囲を読み取れた。他の取得元では失敗している場合がある。 |
| 評価できた | 記載した範囲・観測期間について、ルールを評価するデータが揃った。 |
| 候補あり／評価範囲内で該当なし | ルールに該当した、または評価できた範囲では該当しなかった。環境全体に問題がないという保証ではない。 |
| 未評価 | データ不足、権限不足、API無効、取得失敗など、前提を満たせなかった。理由を確認できる。 |
| 金額算出済み／金額不明 | 検知とは別の状態。金額が不明でも成立した検知と根拠は表示する。 |

各診断で、対象プロジェクト・リソース、取得時点、観測期間、判定条件、未評価の範囲を確認できるようにします。一部の取得失敗では、評価できたルールとできなかったルールを分けます。データ不足を「問題なし」「0件」「支出ゼロ」へ変換しません。取得が完了した空の一覧は、確認済みの範囲に限って対象リソースなしと判断できます。

## 金額より先に根拠を示す

初回の3候補はリソース情報に基づき、請求エクスポートやBigQueryを必須にしません。金額算出には、最新の価格、リソース構成、明確な時間の基準、正しく対応付けられた請求データなどが追加で必要になる場合があります。分からない金額は不明のままにし、一部の金額を全体の合計として示しません。

リソースの推定コスト、特定の変更で削減できる可能性がある金額、実現済みの削減額は区別します。前提、通貨、期間を示し、共有リソースを二重計上しません。候補は所有者、利用目的、復旧要件を見直すきっかけであり、削除の指示ではありません。

自動削除・自動変更、定期実行、Slack通知は初回診断に含めません。[仮想分類と簡易Showback](./getting-started#検討中の機能)は別の機能候補として維持し、対象バージョンは未定です。
