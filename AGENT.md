# Agent Guidelines

## Project Context

LuckyCat is a public repository for a streamlined, minimalist FinOps tool. Keep contributions aligned with the project's focus on simplicity, affordability, and practical usability.

## Local Development and Pushes

When using Codex for local development, leave changes available for human review before they are pushed. Do not push unless the developer explicitly instructs you to do so. Permission to edit files or create commits does not imply permission to push.

## Communication Language

- Use English for public-facing GitHub content, including commit messages, pull request titles, descriptions, review comments, and issue discussions.
- In local Codex sessions and other private development conversations, use the developer's language. The original author is Japanese and prefers Japanese.

## Public Repository Privacy

- Keep development conversations between humans and AI in Codex or the relevant private tool. Do not expose intermediate conversations in commit messages, pull request descriptions, comments, or other public content.
- Publish process records only when the developer explicitly designates them for publication and they are deliberately added as repository files. Do not infer permission to publish a conversation from its relevance to a change.
- Preserve the developer's ability to decide what is public, protect their privacy, and think freely without exposing those thoughts to third parties.
- Keep commit messages short, simple, and easy to audit. Describe the committed file changes directly; avoid lengthy narratives, conversation transcripts, and unnecessary development history.
- Do not include information from other projects or nonpublic information in committed files, commit messages, pull requests, or other public content unless explicitly authorized for publication.
- The author frequently uses voice input. Treat incidental thoughts, self-talk, and unintended transcriptions as private conversation, not material to reproduce in public artifacts.
- Before committing or preparing public-facing content, check that it contains only information intended for publication and necessary to explain the contribution.
